# 山东移动盲插 · 一页纸接线（照做即可）

> 适用：光猫 4 口都能上网+看电视（盲插），现在 `光猫→傻瓜交换机→机顶盒+电脑`，能上网能看电视但**抓不到包**。
> 原因一句话：**电脑没进 IPTV 专网**。解决办法一句话：**让机顶盒的流量"经过"电脑**。
> 完整原理/更多方案见 [山东移动盲插抓包方案.md](山东移动盲插抓包方案.md)。

---

## 第 1 步：接线（二选一）

### ✅ A. 电脑有 2 个有线网口 → 网桥串联（推荐，不花钱）

```
光猫盲插口 ──> 电脑网口A
电脑网口B  ──> 机顶盒
电脑 WiFi  ──> 家里路由器（电脑上网走这条，别动）
```

1. 按上图接线，机顶盒先断电。
2. Windows：`控制面板→网络和共享中心→更改适配器设置`，Ctrl 选中**网口A+网口B**→右键→**桥接**，等几秒出现「网桥」。
3. 机顶盒上电，**确认电视还能正常看**（说明接对了）。

> 只有 1 个网口？买个 **USB 有线网卡**凑成双口走 A，最省事。

### ✅ B. 只有 1 个网口、有管理型交换机 → 端口镜像

```
光猫盲插口 ──> 交换机 口1
机顶盒     ──> 交换机 口2（源口）
电脑有线口 ──> 交换机 口3（镜像目的口）
```

1. 进交换机管理页找「端口镜像 / Port Mirror」。
2. **源口=口2（机顶盒），方向=收发 both，目的口=口3（电脑）**。
3. 电脑接口3，机顶盒确认能正常看电视。

---

## 第 2 步：抓包（要管理员）

右键「以管理员身份」打开命令行，运行：

```bat
WushuangIPTV-CLI.exe capture --seconds 90 --out channels.json
```

抓包这 90 秒里：**机顶盒开机重启一次，再用遥控器逐个换台，每个频道停 3~5 秒**。

---

## 第 3 步：验证 + 出播放列表

```bat
WushuangIPTV-CLI.exe verify --channels channels.json --out verified.json
WushuangIPTV-CLI.exe m3u --channels verified.json --outdir D:\iptv
```

得到 `iptv.m3u`（组播版）+ `iptv-http.m3u`（转发版），VLC 打开即可。

---

## 第 4 步：结果不对怎么办（一句话版）

| 现象 | 怎么办 |
|---|---|
| 抓包 0 结果 | 确认是**管理员**运行、机顶盒**开机换台**了、接线按上面接对 |
| verify 全 `bytes=0` | 电脑还没进 IPTV 专网（网桥/镜像只能抓地址）→ 看[完整方案](山东移动盲插抓包方案.md)的方案三/四，或直接用机顶盒实播核对 |
| 弹防火墙 | **点「允许访问」**，点了取消就收不到流 |

---

## 三条铁律

1. 抓包结果里的**机顶盒账号只在本机用，分享前脱敏**。
2. 转发服务**仅限局域网，别映射公网**。
3. **普通路由器别乱接**（会把电视搞坏）；改光猫/路由前**先截图记录原配置**。
