# 无双IPTV抓源工具 · 使用说明

> **作者：锤无双** · [B站视频教程](https://www.bilibili.com/video/BV1hTxx69EFY/) · **QQ群：170621740**
> Windows 单文件绿色版 v2.0.0 · 无需安装任何驱动/运行库 · 双击即用（自动请求管理员权限）

## 一、这个工具能做什么

1. **接线向导**：回答几个硬件问题（电脑有没有 LAN 口/WiFi、交换机几口、机顶盒/光猫/路由器网口情况），自动生成专属的插拔网线步骤 + 拓扑图。
2. **抓包分析**：用 Windows 内置 `pktmon` 抓包（**不用装 Wireshark/Npcap**），机顶盒换台时自动发现组播直播地址（IGMP 加组 + 组播流），自动去重、过滤噪声。
3. **频道验证**：原生加入组播组收流，解析 MPEG-TS（PAT/PMT/SDT/H.264 SPS），**不依赖 ffmpeg**，自动得出频道名、编码、分辨率、可用性。
4. **全国参考库**：内嵌 **31 省 × 电信/联通/移动/广电** 共 82 个列表、14000+ 频道（社区开源数据，浙江电信经实测校验），按省份+运营商一键载入。
5. **生成 M3U**：一键生成 `udp://` 组播直连版和 `http://` udpxy 转发版播放列表，**指定目录保存/更新**，支持与已有文件合并、频道变化自动更新。
6. **转发服务（可选）**：内置 udpxy 等价服务，组播转 HTTP 单播，WiFi 设备播放更稳；播放列表地址直接复制到 VLC/Kodi/DIYP。

## 二、系统要求

- Windows 10 1809+ 或 Windows 11（内置 pktmon）
- 管理员权限（exe 已内置 UAC 清单，双击自动弹确认）
- 抓包场景硬件：**带 LAN 口 + WiFi 的电脑**、**3 口以上傻瓜交换机**（无管理功能）、机顶盒（有网口）
- 首次运行若被 SmartScreen/杀毒软件拦截：右键 → 属性 → 解除锁定，或选择"仍要运行"（PyInstaller 单文件程序常见误报，源码随包提供可自行审计/重打包）

## 三、快速开始

### 场景 A：第一次抓源（机顶盒还在用）

1. **① 接线向导**：如实回答问卷 → 点「生成接线指导」→ 按步骤接线：
   ```
   光猫 ITV 口 ──> 傻瓜交换机 口1
   机顶盒网口 ──> 傻瓜交换机 口2
   电脑有线口 ──> 傻瓜交换机 口3
   电脑 WiFi  ──> 保持连接家里路由器（上网不受影响）
   路由器 WAN ──> 光猫上网口（保持不动）
   ```
   > 电脑有线口显示"无 Internet / 169.254.x.x"是**正常现象**——它进了 IPTV 专网。
2. **② 抓包分析**：点「开始抓包」→ 机顶盒开机重启，或用遥控器**逐个换台，每个频道停 3~5 秒** → 点「停止并分析」（默认 90 秒自动停止）→ 选中结果「加入频道列表」。
3. **③ 频道验证**：组播网卡选**有线口**（169.254.x 也可以）→「验证全部」→ 自动命名 + 标出可用/不可用。
4. **④ 生成 M3U**：选输出目录 →「保存/更新」→ 得到 `iptv.m3u`（组播版）+ `iptv-http.m3u`（转发版）。
5. 播放：VLC 打开 m3u 文件即可；手机/电视走 WiFi 建议用 ⑤ 转发服务的 HTTP 地址。

### 场景 B：已桥接合并网络（机顶盒已退役）

1. **① 接线向导**：选「已按教程把 IPTV 桥接进局域网」→ 确认桥接线还在。
2. **③ 频道验证**：点「📚 选择地区载入参考库」→ 选你的**省份+运营商** →「验证全部」。
3. **④ 生成 M3U**：保存到你指定的目录（如 NAS 共享盘映射的目录）。

### 场景 C：只想让全家直接看（进阶桥接）

抓源完成后，把**路由器 LAN 也插进傻瓜交换机**（口 4）→ 两网二层合并 → 组播进入家庭局域网 → 全家设备直接播放 `udp://` 版 m3u，**无需任何服务开机**。
- 安全性：IPTV 的 DHCP+ 服务器不响应普通设备，不会抢路由器 DHCP（实测）。
- ⚠ 合并后若重新接回机顶盒，它可能从路由器拿错 IP 导致认证失败 → **拔掉桥接线即恢复隔离**。

### 场景 D：路由器带 IPTV 口/VLAN 绑定（免交换机，推荐新路由用户）

很多新路由（TP-Link/华为/小米/华硕等）自带 IPTV 口/VLAN 绑定/单线复用，可**代替傻瓜交换机**：
1. 光猫 ITV（或单线复用 VLAN）→ 路由 WAN；在路由设置里把某个 LAN 口（如 LAN4）绑定为 **IPTV 口**。
2. **机顶盒接该 IPTV 口**；**电脑接普通 LAN 口**。无需傻瓜交换机、无需改光猫接线。
3. 若路由有 **IGMP Proxy / 组播转发 / 组播增强**：开启后组播进入整个 LAN，电脑在普通 LAN 口即可抓包/验证，最方便。
4. 若组播不进 LAN：把电脑也接 IPTV 绑定口（若支持多口），或在该 IPTV 口下接傻瓜交换机分给机顶盒+电脑。

向导里选「路由器带 IPTV 口/VLAN 绑定」即按此生成步骤与拓扑图（见截图 7）。

### 场景 E：抓完一键推送到 NAS（7×24 全家看）

在 ④ 生成 M3U 页下方「推送到 NAS」区：
- **SMB 共享/映射盘**：填 `\\NAS_IP\共享名\iptv`（或已映射的盘符如 `Z:\iptv`）。若需凭据，填账号密码（工具会自动建立连接）；也可先在 Windows 映射好网络驱动器。
- **WebDAV**：群晖/威联通开启 WebDAV 服务后，填 `http://NAS_IP:5005/目录` + 账号密码。
- 点「📤 一键推送到 NAS」：先保存 M3U（含 udp/http 配对版）再推送；勾选「保存后自动推送」则每次保存自动同步。
- NAS 侧用 Tvheadend 或 udpxy 读取推送过来的 m3u，即可 7×24 转发，电脑可关机。

## 四、全国参考库与更新（运营商/地区变了怎么办）

参考库数据来自社区开源仓库 [xisohi/CHINA-IPTV](https://github.com/xisohi/CHINA-IPTV)（每日自动更新），打包时内嵌进 exe。三种更新方式：

| 方式 | 操作 |
|---|---|
| **在线更新** | ③ 页「🔄 在线更新参考库」→ 自动尝试国内加速镜像 / GitHub API / git 克隆，成功后写入程序目录 `refdb.json` 并立即生效 |
| **离线导入** | 从 QQ 群（170621740）下载最新 `refdb.json` → ③ 页「导入参考库文件」；或直接放到程序目录（自动覆盖内嵌库） |
| **换运营商/换地区** | 重新「选择地区载入参考库」选新的省份+运营商；参考库只是候选，**一切以本机实测验证为准** |

- 软件**只在你点击更新时联网**，平时不后台联网、不上传任何数据。
- 想恢复出厂内嵌库：删除程序目录的 `refdb.json` 即可。
- 软件本体更新：替换 exe 单文件即可，配置（`WushuangIPTV.json`）与频道列表自动保留。

## 五、播放方法

| 设备 | 方法 |
|---|---|
| 电脑 VLC | 媒体 → 打开文件（m3u）或打开网络串流 `udp://@233.50.201.118:5140` |
| 手机/电视 VLC | 打开 m3u 文件/URL；WiFi 卡顿就用 HTTP 转发版 |
| Kodi | PVR IPTV Simple Client → 指向 m3u 路径/URL |
| DIYP/电视盒子 | 填 m3u 地址（HTTP 版兼容性最好） |
| 路由器 udpxy | 把 HTTP 版里的 `主机:端口` 改成你路由器的 udpxy 地址（④ 页可直接设置） |

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 抓包 0 结果 | 是否管理员运行？机顶盒是否开机换台？交换机是否傻瓜型（网管型要关 IGMP Snooping）？网线是否插紧？ |
| 有线口无 169.254 地址 | 网线/交换机口坏，换口；确认接的是 ITV 信号线不是上网线 |
| 验证全部失败 | 组播网卡选错：搭线阶段选有线口(169.254.x)，已桥接选有线口(192.168.x)；个别路由器 WiFi 不转发组播 |
| 个别频道不可用 | 停播/未开通/外地地方台不在本地播发；运营商随时可能调整组播地址，以实测为准 |
| 播放卡顿 | 组播过 WiFi 依赖路由器组转单能力 → 用 ⑤ HTTP 转发，或播放设备走有线/5G WiFi |
| HTTP 版地址失效 | 电脑 IP 变了：路由器里给电脑绑定静态 IP，重新生成 M3U |
| 在线更新失败 | 网络波动/镜像失效，稍后重试；或 QQ 群下载 refdb.json 离线更新 |
| 抓包文件太大 | 默认分析后自动删除；勾选"分析后保留 pcap"可留存复盘（程序目录 cap_temp） |

## 七、技术原理（为什么这样做）

- **组播免鉴权**：IPTV 直播流是组播 MPEG-TS，走光猫 ITV 口独立 VLAN。任何设备进入该 VLAN 并 IGMP 加组即可收流；DHCP+ 鉴权只影响单播业务（EPG/回看/时移）。
- **傻瓜交换机泛洪**：无 IGMP Snooping 的交换机会把组播泛洪到所有口，电脑有线口因此能"搭线"抓到流。网管型交换机会把组播只发给机顶盒 → 抓不到。
- **pktmon 抓包**：Windows 内置，全 NIC 捕获（会重复 6~8 份，工具已去重）；`etl2pcap` 产物实为 pcapng，工具两种格式都支持。
- **网卡硬件过滤**：没加组时网卡直接丢弃组播帧，"统计为 0"不代表线路上没有流——所以验证必须真实加组，工具就是这么做的。
- **原生 TS 解析**：PAT→PMT 得编码类型，SDT 得频道名（中文 GB2312/UTF-8 自适应），H.264 SPS 得分辨率（含隔行裁剪修正）。

## 八、隐私与安全

- 软件**不后台联网、不上传任何数据**；在线更新仅在你点击时发生，只下载公开频道列表。
- 内嵌参考库只含组播地址与频道名等公开信息，**不含任何账号、密码、个人数据**。
- 抓包时看到的机顶盒账号等信息**仅显示在你本机屏幕**，不写入配置文件；分享抓包文件前注意脱敏。
- 转发服务**仅限局域网**使用，禁止把端口映射到公网。
- 桥接合并把 IPTV VLAN 暴露给家庭局域网，家庭内可信即可；介意可拔桥接线回滚。
