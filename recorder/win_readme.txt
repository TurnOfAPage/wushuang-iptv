无双IPTV录像工具 · Windows 使用说明
====================================

【先做一步（消除安全警告）】
下载的 zip 带"来自 Internet"标记：右键 zip → 属性 → 勾选"解除锁定" → 确定，再解压。
（否则双击 bat/vbs/lnk 会弹"未知发布者"安全警告。）

【打开方式（任选）】
1. 双击 无双IPTV录像工具.pyw  —— 推荐（本机已装 Python 时）：无黑窗、无警告，
   走系统已安装 Python（杀软信任）进程链。
2. 双击 无双IPTV录像工具.bat（或 launch_gui.bat）—— 任何机器可用（无 Python 时用包内 python\ 运行时）；
   会闪一下黑窗后出界面。
3. 命令行：recorder_cli.bat <子命令>（如 record start / record list / proxy）。

【为什么没有 exe】
火绒等杀软按"进程链+安装路径"信任程序：未签名 exe（单文件解包/文件夹版/编译启动器）
及其子进程写"下载/文档"等保护目录会被拒（实测四种形态均被拦）。
.pyw/.bat 经系统签名进程（pythonw/cmd/wscript）进入信任链，杀软开着也能录、
默认录像目录=系统下载文件夹\无双IPTV录像（可在设置改）。
如坚持 exe 形态：在火绒信任区添加本目录，或安装到 Program Files（需管理员），
或购买代码签名证书——三者任选其一后 exe 才不被拦。

【录像三步】
① 频道与录制：导入频道文件（主工具 verify 结果 JSON/M3U）或 载入参考库→验证全部；
   选中频道行 → ⏺ 录制选中 → 设时长 → 确定。
② 录像管理：进度/停止/预约/删除/设置（容量上限默认100G、保存文件夹）。
③ 常驻服务：启动后局域网播放列表 http://<本机IP>:9999/playlist.m3u 与
   录像列表 /recordings.m3u；NAS 部署见 docker/README.md。
