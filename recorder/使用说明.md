# 无双IPTV录像工具 · 使用说明（GUI）

> ⚠ **本工具仅供个人研究学习使用，请在 24 小时内删除录制文件。传播录制文件会导致版权风险，该风险与本软件无关。**
> v1.0.0 · 独立产品（不需要录像的用户无需安装）· 作者：B站-锤无双 · QQ群 170621740
> 命令行/NAS 部署见 [CLI使用说明.md](CLI使用说明.md)；产品总览见 [README.md](README.md)。

## 原理一句话

IPTV 直播是组播流，进 ITV 专网加组即可免鉴权接收。本工具把收到的流**存成 TS 文件**，
事后局域网点播。**只能录开始之后的内容，不能回溯过去**（运营商真回看需机顶盒鉴权，不做）。
常开电脑/NAS + 预约录像 = 错过的直播随时补看。录像**不需要管理员权限**。

## 界面四页

### ① 频道与录制

1. **导入频道文件…**：选主工具「无双IPTV抓源工具」`verify` 的结果 JSON（或任意 M3U）。
   没有主工具？点「📚 载入参考库」选省份+运营商 → 「验证全部」实测（需有线网卡接入 IPTV 专网/桥接网络）。
2. 顶部选**组播网卡**（搭线阶段选有线口 169.254.x 也可；已桥接选 192.168.x）。
3. 选中频道（可多选）→ **⏺ 录制选中** → 填时长（分钟）或「录到 HH:MM」→ 确定。
   - 录制中顶部显示 `⏺ 频道名 已录 时长 / 大小`；「■ 停止全部录制」提前收尾（文件保留，标记部分）。
   - 并发默认 2 路（光猫可能限速加组，勿贪多）。
4. 录完的文件在 `录像目录/ts/` 下，**VLC/Kodi/PotPlayer 直接打开就能播、能拖**。

### ② 录像管理

- **节目单（EPG）**：点「🔄 更新节目单」主动联网拉取公共 XMLTV（epg.pw/51zmt 等，可填自定义地址）。
  「启动时自动更新」默认不勾——勾选后每次启动会联网，请知情选择。
- **录像文件表**：频道/节目/开始/时长/大小/状态/断流次数。
  - 刷新 · 停止选中录制 · 删除选中录像 · 打开录像目录 · 复制点播地址（需 ③ 页服务在运行）。
  - 右上「配额: 已用/上限 GB」+「立即清理」：超配额自动按最旧已完成清理，**绝不删进行中/待录**。
- **预约计划表**：
  - 「＋ 新增预约…」→ 选频道 → 两种模式：
    - **手动时间段**：日期 + 起止 HH:MM（结束早于开始自动按跨午夜处理）；
    - **EPG 节目单点选**：列出该频道未来 7 天节目，双击即预约（需先更新节目单）。
  - 预约自动留余量：提前 60s 开录、延后 120s 收尾（防节目提前/拖堂）。
  - **预约到点执行需要 ③ 页常驻服务在运行**；服务没开时计划保存不丢，启动后自动恢复。
  - 取消选中 · 清理历史（移除已完成/错过/已取消计划）。

### ③ 常驻服务

一个服务 = 直播转发（udpxy 等价）+ 预约调度 + 录像点播。

1. 设端口（默认 9999）、组播网卡、录像目录（NAS 场景指向挂载卷）、配额、并发。
2. **▶ 启动服务**（首次弹 Windows 防火墙提示请点「允许(专用网络)」，否则收不到流）。
3. 复制地址到播放器：
   - 直播列表 `http://<本机IP>:9999/playlist.m3u`
   - **录像列表 `http://<本机IP>:9999/recordings.m3u`**（VLC/Kodi/TiviMate 点播拖动）
   - 状态页 `http://<本机IP>:9999/status`
4. 状态区每 2 秒刷新：活跃直播流、录制中进度、待录计划、配额。

⚠ **仅限局域网，禁止把端口映射到公网。** 7×24 预约推荐 NAS 部署 CLI（见 CLI使用说明.md）。

## 可靠性（自动处理，无需干预）

- 断流 6s 自动重加组续录同一文件（IGMP 60s 续期防光猫侧老化）；断流次数可查。
- 程序/设备重启：在录计划续录剩余时段；过期计划标「错过」（CLI 可设 `--missed remainder` 续录）。
- 磁盘将满优雅停止；单文件超 4GiB/2h 自动分段（点播端无感拼接）；索引损坏从文件名重建。

## 常见问题

| 现象 | 原因/处理 |
|---|---|
| 录制 0 字节 | 新 exe 首次运行防火墙没点「允许」；或组播网卡选错；或频道停播（先「验证全部」） |
| 预约没执行 | ③ 页服务没启动；或到点时电脑关机/睡眠（预约需常开，推荐 NAS） |
| 录像列表打不开 | 服务没启动；或 IP 变了（重新复制地址） |
| 拖动不精确 | TS 无索引按码率估算，秒级精度属正常；换 VLC/Kodi 体验最佳 |
| 节目单更新失败 | 公共源时效变化，换个源地址或稍后重试；不影响手动时间段预约 |
| 磁盘占用大 | 每小时每频道约 1~3.6GB（4K 更高）；调小配额或缩短预约 |

## 隐私与安全

不接触机顶盒账号；不上传数据；EPG 仅按钮主动更新（自动更新为显式勾选）；
服务仅限局域网；录像仅供个人观看。
